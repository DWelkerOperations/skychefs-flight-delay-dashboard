# SkyChefs Flight Delay Performance

Branded static wrapper for the SkyChefs flight delay dashboard.

- `index.html` provides the approved SkyChefs brand treatment.
- `dashboard.html` contains the self-contained analytical dashboard.
- `assets/SkyChefs-logo-approved.svg` is the unmodified approved logo asset.

The data is a static snapshot through July 20, 2026. It is not a live connection.
